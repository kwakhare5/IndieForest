# 0001 — Procedural 3D Engine via React Three Fiber

We use `@react-three/fiber` v9 and `three@0.170.0` for all island and tree rendering rather than 2D sprites or generative AI images.

Procedural 3D geometry enables real-time sunlight casting, smooth contact shadows, dynamic day/sunset/night cycles, and live wind swaying with zero API latency.
